# 📚 Book Management System

A modern React-based Book Management System with full CRUD operations.

---

## 🚀 Features

- Add Books
- Edit Books
- Delete Books
- Search Books
- Filter Books by Genre
- Responsive UI
- API Integration using JSON Server

---

## 🛠️ Technologies Used

- React.js
- Vite
- Axios
- JSON Server
- CSS

---

## ⚙️ Installation & Setup

### Clone Repository

```bash
git clone https://github.com/vaishnavipagar/book-management-system
```

### Go To Project Folder

```bash
cd book-management
```

### Install Dependencies

```bash
npm install
```

### Start JSON Server

```bash
npm run server
```

### Start React App

```bash
npm run dev
```
